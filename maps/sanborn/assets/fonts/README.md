# Sanborn Text

Sanborn Text Regular, Semibold and Italic are name-table-only derivatives of Adobe's
**Source Serif 4 Small Text**, version 4.005, pinned to revision
`80d3f8894c09c937bebfa9011247d2e1c79fd6f4`.

The small-text optical cut retains sturdy strokes and open counters at annotation sizes.
Outlines, metrics, hinting and character coverage are unchanged. The derivative family name
respects Adobe's reserved name and avoids a numeric family name in browser canvas font selection.
Full names are `Sanborn Text Regular`, `Sanborn Text Semibold` and `Sanborn Text Italic`.

Only name-table records 1, 2, 3, 4, 6, 16 and 17 change. Original input checksums are in
`upstream-sha256.json`; copyright and the complete SIL Open Font License 1.1 are in `LICENSE.txt`.

To reproduce, download `TTF/SourceSerif4SmText-{Regular,Semibold,It}.ttf` from the pinned upstream
revision, verify the checksums, install `fonttools==4.55.3`, and run:

```sh
python ../prepare-fonts.py /path/to/upstream/TTF .
```

[Upstream source](https://github.com/adobe-fonts/source-serif/tree/80d3f8894c09c937bebfa9011247d2e1c79fd6f4)
