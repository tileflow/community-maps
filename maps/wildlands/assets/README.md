# Original Wildlands artwork

All eleven SVGs were drawn for this map from geometric vector primitives:

- `wildlands-tree.svg`, `wildlands-tree-round.svg`, `wildlands-tree-pine.svg`:
  individual adventure-map trees with an ink outline, olive canopy, light facets and a short trunk.
  These drawings are anchored to mapped tree points. No repeating woodland pattern is included.
- `wildlands-parchment.pattern.svg`: quiet, seamless paper flecks at 128 px.
- `wildlands-camp.svg`, `wildlands-shelter.svg`, `wildlands-meal.svg`,
  `wildlands-monument.svg`, `wildlands-discovery.svg`, `wildlands-nature.svg`: colored teardrop destination symbols,
  redrawn with tent, tunic, cooking pot, Triforce, shrine and leaf-mask motifs from the requested Zelda visual language.
- `wildlands-summit.svg`: golden Triforce-style exploration symbol.

The screenshots supplied by the user informed color, density, symbols and visual hierarchy.
No source pixels or extracted game artwork are bundled. The SVG drawings follow this
repository's Apache-2.0 license. The separately bundled Hylia Serif and Noto Sans fonts
retain their own conditions; see [font provenance](fonts/README.md).
