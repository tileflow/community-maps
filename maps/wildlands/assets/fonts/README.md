  Project Authors. Unchanged static face from the official Google Fonts repository
  [google/fonts `ofl/alegreyasc`](https://github.com/google/fonts/tree/5bb28733cec313b63fbd415b574b5ae35c8aa8b8/ofl/alegreyasc),

- `NotoSans-Regular.ttf`: **Noto Sans Regular**, unchanged static hinted face from
  [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/c971829a87e7920f960e7277c3dafd9bedd3c601/hinted/ttf/NotoSans),
  revision `c971829a87e7920f960e7277c3dafd9bedd3c601`, under SIL OFL 1.1.
  The complete license is in `LICENSE-NotoSans.txt`.

Alegreya SC is the map's display face: a calligraphic book serif with lining figures, so
elevations such as `1211 M` stay legible in uppercase labels. It covers Latin, Latin Extended,
Greek, Cyrillic and Vietnamese. Names remain geographically accurate; Noto fills any remaining
characters and renders road names and contour measurements.
Tileflow prepares these local font files, without relying on a remote glyph endpoint.
`LICENSE.txt` combines both complete licenses for the generic asset preparation pipeline.
