# Wildlands fonts

- `HyliaSerifBeta-Regular.otf`: **HyliaSerifBeta-Regular**, version 0.009, downloaded
  unchanged from [Omni Jacala / Artsy Omni](https://artsyomni.com/hyliaserif).
  This is a BOTW-inspired fan typeface, not an official Nintendo asset. Its author's
  conditions and provenance are recorded in `NOTICE-HyliaSerif.txt`; it is not OFL.
- `NotoSans-Regular.ttf`: **Noto Sans Regular**, unchanged static hinted face from
  [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/c971829a87e7920f960e7277c3dafd9bedd3c601/hinted/ttf/NotoSans),
  revision `c971829a87e7920f960e7277c3dafd9bedd3c601`, under SIL OFL 1.1.
  The complete license is in `LICENSE-NotoSans.txt`.

Hylia is the map's display face. Names remain geographically accurate; Noto fills
missing accented letters and non-Latin glyphs, and renders contour measurements.
Tileflow prepares these local font files, without relying on a remote glyph endpoint.
`LICENSE.txt` combines the notices for the generic asset preparation pipeline.
